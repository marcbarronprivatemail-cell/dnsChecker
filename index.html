DNS Checker

Educational Platform Detection Demonstration

This demonstration showcases how the DNS Checker API detects and identifies different email platforms through advanced fingerprinting techniques. Click on any platform below to see an example of how it would appear after successful detection.

📚 About This Demo

The DNS Checker API uses multiple detection methods including DNS record analysis (MX patterns, SPF, DMARC), HTTP header analysis, path detection, cookie fingerprinting, HTML content analysis, and TLS certificate inspection. Each platform has unique fingerprints that allow accurate identification.

🔧 Detection Methods

DNS Analysis: MX record patterns, SPF, DMARC, MTA-STS records
HTTP Fingerprinting: Server headers, X-headers, status codes
Path Detection: Common webmail paths and redirects
Cookie Analysis: Platform-specific session cookies
HTML Content: Meta tags, keywords, form actions
TLS Certificates: Certificate CN and organizational identifiers

This is an educational demonstration of platform detection capabilities. For the actual DNS Checker API, visit the GitHub repository.
